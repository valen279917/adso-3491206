01-Emmet

Plugin para codificación más rápida en HTML y CSS.

01-Child >
Crea elementos hijos (anidación).

Ejemplo:

ul>li>a ↔️

Resultado:

<ul> <li> <a href=""></a> </li> </ul>

02-Sibling
Crea elementos hermanos (anidación).

Ejemplo:

section+header+nav↔️

Resultado:

<section></section> <header></header> <nav></nav>

03- multiplicar *
Repeats elements multiple times.

Ejemplo:

ul>li * 3↔️

Resultado:

<ul> <li></li> <li></li> <li></li> </ul>

04-Class: .
Creates a class attribute.

Ejemplo:

menu.mainmenu↔️

Resultado:

<menu class = "main"></menu> <div class = "container"></div>

05-clases: ... #
Creates multiple class attributes.

Ejemplo:

div.clase1.clase2.clasen ↔️

Resultado:

<div class = "clase1 clase2 clsen"></div>

06-Id #
Crea un atributo de ID.

Ejemplo:

nav#navigation123 ↔️

Resultado:

<nav id="valenn1234"></nav>

07-Text {}
Inserta contenido de texto.

Ejemplo:

div{Lorem Ipsum Dolor} ↔️

a{Click Aquí} ↔️

Resultado:

<p>Lorem Ipsum Dolor.</p> <a href="">Click Aquí</a>

08-Custom Attribute []
Crea atributos personalizados.

Ejemplo:

a[href=www.google.com] ↔️

Resultado:

<a href="www.google.com"></a>

09-Item Numbering
Añade números consecutivos.

Ejemplo:

ul>li.num$*3 ↔️

section>article.sec$$$*3 ↔️

Resultado:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

10-Reverse Numbering
Invierte el orden de numeración.

Ejemplo:

ul>li.num$*3 ↔️

section>article.sec$$$*3 ↔️

Resultado:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

11-Base Numbering
Define un número base para secuencias

Ejemplo:

ul>li.num$@3*4 ↔️

Resultado:

<ul> <li class="num3"></li> <li class="num4"></li> <li class="num5"></li> <li class="num6"></li> </ul>

12-Climb Up
Sube un nivel.

Ejemplo:

section>article>div^p ↔️

Resultado:

<section> <article> <div></div> <p></p> </article>

13-Grouping
Agrupa elementos juntos.

Ejemplo:

(header>nav)+footer ↔️

Resultado:

<header> <nav></nav> </header> <section> <article></article> </section>

14-Lorem
Genera texto de relleno.

Ejemplo:

lorem5 ↔️

Resultado:

<p>Lorem ipsum dolor sit amet.</p>

15-HTML Documents
Crea varios tipos de documentos HTML.

Ejemplo:

html:5 ↔️

Resultado:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport"> <title>Document</title> </head> </html>

16-Meta Tags
Genera texto de relleno.

Ejemplo:

meta:vp ↔️

Resultado:

<meta name="viewport"
